Cybersecurity Login Log Analyzer

Project Overview

A beginner-friendly Python cybersecurity project that analyzes fictional login records to identify suspicious authentication activity.

Objectives

The project demonstrates basic security log analysis and detection of potentially suspicious login behaviour.

Detection Features

- Repeated failed login attempts from the same IP address.
- Successful logins following multiple failed attempts.
- Successful logins outside normal working hours.

Tools and Technologies

- Python
- Google Colab
- CSV files
- Python standard library

Project Files

- "Cybersecurity_Login_Log_Analyzer.ipynb" — Python notebook containing the analysis.
- "brute_force_detection_report.csv" — CSV report generated by the brute-force detection exercise.

Testing

The project uses fictional login records and documentation-only IP addresses. It does not connect to or monitor real systems.

Learning Outcomes

- Reading and analysing CSV security logs.
- Identifying suspicious authentication patterns.
- Applying basic Python automation.
- Generating security reports.

Disclaimer

This is an educational portfolio project. Its alerts indicate patterns worth investigating; they do not prove that an account has been compromised.
